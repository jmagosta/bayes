Purpose: 
This folder contains a script for the Mac OS that automates the copy of the most recent Zoom audio file to the podcast Google Drive folder.  This can be run immediately after completing a Zoom session.

What is does:
You give the audio file descriptive label for the file when you start the process.  When you initiate this script it will wait until the audio file has been converted on the local computer, then copy it. After the file copy is uploaded, the script confirms that the copy is available by sending an email to talks@kannondo.org
